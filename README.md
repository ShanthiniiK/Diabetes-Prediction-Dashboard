I have developed the The Straemlit Dashboard for diabetes Prediction.

Features
Visualizations
Diabetes Class Distribution
Age Distribution Histogram
BMI vs Blood Glucose Scatter Plot (Colored by Diabetes Status)
Interactive Features
Sidebar filters for Age Range, BMI Range, Blood Glucose Range, and Gender.
User input controls for patient information used in diabetes risk prediction.
Predictive Output

The dashboard uses a trained XGBoost classification model to:

Predict diabetes risk.
Display the probability of diabetes risk.
Show High or Low Risk prediction result.
Dataset

The dashboard uses the Diabetes Prediction Dataset attributes as below:

Gender
Age
Hypertension
Heart Disease
Smoking History
BMI
HbA1c Level
Blood Glucose Level
Diabetes (Target Variable)
